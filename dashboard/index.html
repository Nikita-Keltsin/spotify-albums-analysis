Раздел 2.7 · параметры по обучающей выборке (80%)

release_year

Левый хвост из старых альбомов: MinMax сжимает почти всё к единице.

album_minutes

Сильная правая асимметрия: длинный хвост сохраняется при любом методе.

label_count

Самый тяжёлый хвост: после MinMax медиана почти 0, после Robust максимум уходит далеко вправо.

Форма распределения не меняется ни одним методом

Все три метода — линейные преобразования, поэтому асимметрия одинакова до и после. Итоговый выбор — логарифм для асимметричных признаков, затем StandardScaler, обученный только на обучающей выборке.
